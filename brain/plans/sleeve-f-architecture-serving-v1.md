## 1. Training mechanics (final)

**1.1 Learner contract.** Single shallow LightGBM Huber net-R regressor (roadmap params) with ALL previously implicit knobs frozen: `objective=huber`, **`alpha=0.90`**, `min_data_in_leaf=100`, **`min_sum_hessian_in_leaf=1e-3`**, expanded defaults committed, NaN/zero-as-missing treatment, categorical handling, feature order, row order. Day-balanced weights: row i in session d gets `w = 1/n_d` (each session totals weight 1; no further rescaling; L1/L2/Hessian semantics interpreted under exactly this normalization). Per-leaf audit after every fit: raw rows, distinct sessions, effective weight, era composition; **artifact fails if any leaf has < 20 distinct sessions**.

**1.2 Chronology, purging, inner validation.** Boundaries between complete sessions. Purge = remove training rows with `label_end ≥ B`; validation/test rows near the boundary stay. Three separate checks: label non-overlap, training-only transform fitting, controller-state isolation. Boundary test fixtures: overnight gap, holiday, truncated session (2025-09-26 type), expiry/roll seam, exact timestamp equality, 14:29 terminal decision, duplicate/non-monotone timestamps, timezone normalization. Inner validation = last chronological 20% of complete training sessions, used ONLY for early stopping + fold `best_iteration`. Early stopping monitors **mean of per-session equally-weighted Huber losses** (custom eval — stopping optimizes what fitting optimizes), patience 30. Deployable artifact: median fold `best_iteration` (round-half-up), refit once on all registered pre-shadow data.

**1.3 Controller (final, supersedes roadmap init wording).** Before each session D: take last 60 completed **admissible** sessions strictly before D (frozen admission rule excludes incomplete/corrupted/halted-without-valid-counterfactual/boundary-contaminated sessions); score with the applicable frozen artifact; replay the exact state machine at every distinct historical threshold; pick threshold minimizing |executed − 42|; ties → fewer trades, then higher threshold; frozen for all of session D. Fold initialization: same rule against the last 60 admissible **training** sessions before the OOS boundary (early folds valid — 2020 has ~252 sessions; inner-val overlap accepted, optimism washes out as the window slides). < 60 admissible sessions ⇒ fold invalid, no fallback.

**1.4 Determinism (two gates, not byte equality).** Freeze: container digest, CPU arch, LightGBM binary, OpenMP/BLAS runtime, thread count, histogram mode, all four LightGBM seeds, data/feature ordering, NaN handling. Seed derivation: SHA-256 of `protocol_version|candidate_id|fold_id` → first 8 bytes unsigned big-endian → `1 + (value mod 2147483646)`. Gate 1 (same registered environment): identical prediction vector + canonical structural tree dump. Gate 2 (cross-environment replay): max |Δscore| ≤ 1e-10, |Δthreshold| ≤ 1e-10, and **identical** eligibility/decisions/entries/exits/ledger — score tolerance never excuses a decision mismatch.

**1.5 Artifact bundle** (per fold + deployable, immutable, signed manifest resolving every hash to a retained object): model binary + canonical dump; expanded config; ordered feature schema + hash; fitted transform state; content-addressed feature matrix; raw-data lineage; label/feature/replay/controller/serving code commits; container digest + CPU/runtime declaration; calendar/expiry/roll/cost-era tables; session IDs + cutoff; seeds; controller cohort + threshold provenance; per-leaf support report; golden fixtures (raw input → feature vector → prediction → controller → decision → ledger).

## 2. Post-promotion lifecycle (final)

1. **First promoted artifact: frozen-until-kill (L-A).** Controller adapts; the model never refits. Clean decay attribution.
2. Killed artifact ⇒ trading pauses until an independently authorized successor completes its registered qualification. No silent replacement.
3. **Evergreen annual refit** may be registered later as a distinct policy family — **k+1 once at introduction**, not per refit. Form: annual cadence, expanding window, fixed cutoff/publication lag, identical learner/features, frozen seed + best-iteration rules, fixed activation time, no outcome-conditioned swap or restoration.
4. Each annual artifact gets a 20-complete-session parallel soak = engineering parity only (~14 trades, not evidence). After the evergreen policy itself passes prospective qualification, a passing soak activates automatically; PnL cannot influence activation.
5. Rollback only for reproducible operational corruption, under a signed incident record — never "the old model earned more."
6. Drift/economic alarms may pause or kill; they never trigger retraining.

## 3. Output processing

**3.1 Decision envelope.** One immutable envelope per eligible decision bar (including no-trade and blocked), emitted identically in replay/shadow/live (parity requirement). Fields (full list, registration-grade): schema_version; decision_id, signal_id; protocol_version, candidate_id, environment, mode; session_date, instrument_id, contract_id, decision_bar_id; exchange_ts, receive_ts, process_ts, clock_offset_ms, latency_ms, latency_budget_ms, clock_sync_ok; raw_input_snapshot_id, raw_input_hash, feature_vector_hash, feature_set_hash, missing_required_features, invalid_feature_flags, feature_canary_flags, data_health_state; code_commit, container_digest, model_version, model_digest, replay_version, config_version, config_digest; controller_version, controller_state_hash, controller_computed_ts, controller_cohort_session_ids, controller_cohort_hash, controller_target_trades, controller_realized_trades; score_net_r, threshold_active, ranking_margin, ranking_margin_z60 (diagnostic only — never gates or sizes); eligibility_pass, eligibility_fail_reasons, would_trade, policy_decision (trade|no_trade|blocked), policy_block_reasons; position_state_before, risk_state_version, available_capital, open_exposure, session_realized_r_before, daily_halt_state; manual_override_id, supersedes_decision_id, previous_envelope_hash, envelope_hash, signature_id, audit_write_status.

**3.2 Execution/risk append records** (execution module appends; envelope never mutated; scorer/execution seam explicit — `lots` and broker semantics live here, not in the scorer): execution_event_id, decision_id, order_id, parent_order_id, position_id, execution_policy_version; sent_order, operator_block_reason; intended side/type/quantity/price; broker_sent_ts, broker_ack_ts, broker_order_status, broker_reject_code, exchange_order_id; fill records (id, ts, qty, price, cumulative, remaining); cancel request/ack; position_state_after; expected vs realized spread/slippage/fees/taxes/total_cost_bps (separately); exit_reason/ts/price; gross_r, **policy_net_r, operator_net_r, override_delta_r**; broker_position vs internal_position, reconciliation status/ts; correction_reason, supersedes_execution_event_id, previous_event_hash, event_hash, signature_id.

**3.3 Confidence filtering & regime filters — the answer (principal-facing):**
- The system does not estimate a calibrated win probability. The score ranks expected net-R; the activity controller selects ~0.70 trades/session over time. "Confidence filtering" here = score-based selection and abstention (sessions with nothing above threshold trade zero), not a probability guarantee.
- Score-minus-threshold is logged as a **ranking margin** for diagnostics; it never gates or sizes trades.
- Adding uncertainty/conformal/quantile/news-veto gates would make 0.70 a ceiling and create a new registered policy; none enters C2 or the first C3 contrast. (Deferred ledger: "activity-as-ceiling + abstention gate" is a possible future named policy family.)
- "Regime filters": (1) regime as model INPUT — vol/VIX/time features are in the frozen sets; the tree conditions on observed state (this does not prove stable regimes exist); (2) LEARNED regime gating — rejected (threshold-estimation burden at our trade counts); (3) OPERATIONAL guardrails — stop unsafe execution only (bad data, broken state, exchange/broker failure, fixed risk limits); cannot be invented after losses, cannot improve reported returns, cannot trigger refits.
- Manual halts exist but are closed as a backdoor: **policy return** (frozen counterfactual on contemporaneous data) is the only series used for promotion/research/kill decisions; **operator return** (actual) is for capital; every report shows both + per-override delta. Emergency flattening is a separate signed override type; halts auto-expire at session close; restarts cannot clear a daily halt.

**3.4 Frozen alarm table.** Immediate pause: required bar missing beyond measured-latency limit / stale quote / timestamp reversal / clock skew; NaN-Inf / impossible OHLC / duplicate bar / frozen-price signature / wrong contract / roll mismatch / cross-feed integrity failure; required feature missing or offline-live mismatch; any digest mismatch or golden-path decision mismatch; controller cohort missing-duplicated-inadmissible or threshold computation failure; risk engine / durable state / idempotency store / audit sink unavailable. No-new-entries: broker disconnect / unresolved rejection or partial fill / position mismatch (reconcile; flatten only under separate authority); exchange halt / circuit breaker / calendar mismatch / registered limit-move. Session-scoped: daily −5R policy-loss halt (restart-proof); score NaN or zero variance over a full eligible session → pause before next session; any registered **`must_vary_intraday` canary feature** constant across a full otherwise-valid session → pause before next session (scoped list — clocks/flags legitimately constant are excluded). Kill: registered sequential economic boundary crossed → kill artifact, no automatic successor. Investigate-only: activity outside band one window (pause+reconcile after three consecutive windows — controller/data failure, not economic kill); cost/slippage boundary breach (pause only if execution integrity doubtful); PSI / SHAP drift / feature drift / margin drift → dashboard, never actions. All numeric thresholds frozen from the pre-registration live-parity audit, not taste.

**3.5 Replay-derived activity band** (replaces binomial approximation — exclusivity + 3/day cap break independence; naive 3σ ≈ 31–53 on n=60, p=0.70 is only a sanity anchor): run registered C2 mechanics over all historical WF OOS sessions; form every rolling 60-complete-session window; record executed counts (no PnL/labels involved); pool across both C2 candidates and all folds; bounds = floor(0.5th pct) / ceil(99.5th pct); hash ledgers + window list + quantile implementation + integer bounds into registration; never recompute from live performance — changing the band = protocol amendment.

**3.6 Serving invariants** (from Sol's missing-pieces list, all adopted): decision idempotency across restarts/duplicate bars; exchange/receive/process event-time discipline surviving replay; durable state recovery (daily R, positions, controller history, emitted decision IDs); live/backtest parity harness (captured live snapshot → offline engine → compare feature vector, score, threshold, eligibility, decision); frozen controller admission rule for incomplete/halted sessions; broker reconciliation before every new entry; fail-closed matrix per dependency; late completed bar = skipped, never a delayed order; kill/pause state survives restarts and deploys; counterfactuals use contemporaneously stored inputs only; chain root anchored daily outside the serving trust boundary; retention = strategy life + 7 years; signed role-controlled activation/override/correction records.

## 4. Media news — final ruling (answers the principal's pushback)

**Where the principal is right:** exchange filings do NOT cover investigative exposés, leaks, court/regulator actions reported first by media, geopolitical shocks, foreign competitor/product launches (the AI-launch case), analyst discoveries, or narrative acceleration — and even for results, the filing timestamp does not encode beat-vs-consensus or sector read-through. The Hindenburg and DeepSeek traces (§0) show genuine incremental information: cause attribution, entity/sector propagation graph, source credibility, unresolved-shock state. For a long-only router its main value is **avoiding/down-ranking longs during unresolved media-first contagion** — asymmetric veto value expressed through features.

**Where discipline binds:** generic headline sentiment ≠ standalone 60-min edge; free RSS ≠ PIT archive; licensed history accelerates development but can never substitute for ≥150 fresh forward trades; every taxonomy/severity/cluster/decay constant frozen before outcomes; no retrospective LLM rescoring; no news veto (activity-changing = registered policy, never a guardrail).

**Registered form:** if media wins the (amended) six-week cascade — `minute ex-India → snapshot → options → licensed media event-flow → ADR/ETF → native announcements → wait` — it enters as ONE feature-family contrast at k=102: identical learner/target/controller/eligibility/activity/risk; treatment side adds the frozen media vector: source/severity-weighted entity-resolved event intensity, unresolved-shock state, minutes-since-qualifying-cluster, correction/denial/retraction state, causal affected-index-weight and sector exposure.

**Media audit lane (deltas beyond the announcements lane):** contractual redistribution/use rights across publishers+syndicators; native first-publication AND collector first-receipt timestamps with measured latency; cross-source cluster dedup preserving originating report; credibility/allegation-vs-fact/negation/correction lineage; causal entity→sector→index graph with contemporaneous weights (incl. foreign firms, commodities, countries, themes); historical↔live semantic parity of entity resolution + taxonomy + clustering + severity; append-only payload versions (no in-place RSS overwrite); outage/backfill flags that cannot masquerade as "quiet news"; ≥60-session live parity with thresholds frozen before cascade selection.

**Principal-facing summary (5 bullets):** news can identify cause, affected entities, propagation, novelty, credibility, and unresolved status behind a move · it can plausibly help a long-only model avoid longs during media-first contagion price features haven't resolved · it cannot reliably turn generic headline sentiment into a standalone 60-minute edge · it cannot manufacture out-of-sample evidence — licensed history speeds development, promotion still needs ≥150 post-freeze forward trades · its increment over futures/global/constituent tape is plausible, not assumed, and earns entry only through one registered family contrast.
